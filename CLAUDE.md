# Lamplight project notes

## What this is
A single-file browser game called Lamplight, in lamplight.html. It uses HTML, CSS and JavaScript, and needs no install.

## Rules for Claude
- Keep the game in one file unless I ask otherwise.
- I'm a beginner, so explain each change in plain language.
- Make one small change at a time, and tell me how to test it.
- Don't turn on automatic pull requests or bypass permissions without asking.

## How to test
Double-click lamplight.html and play.

## Tuning numbers
The numbers at the top of the script (OIL_DRAIN, WRECK_LIMIT, BEAM_RANGE and so on) control difficulty.
